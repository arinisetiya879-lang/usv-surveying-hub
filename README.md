## Upload ke GitHub Pages
1. Extract ZIP.
2. Upload `index.html`, `styles.css`, `script.js`, dan folder/file lain ke root repository.
3. Commit changes.
4. GitHub → Settings → Pages.
5. Source: Deploy from a branch → `main` → `/ (root)` → Save.
6. Tunggu deployment selesai.
